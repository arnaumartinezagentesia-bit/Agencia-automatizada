# ADR-005 — Bóveda de Memoria y Política de Curación

- **Estado:** Aceptado
- **Fecha:** 2026-08-26

## Contexto
La memoria viva debe ser fiable, no ruidosa ni contradictoria.

## Decisión
- Solo el curador de memoria (o el propietario) promueve lecciones.
- Las contradicciones se marcan como conflicto pendiente, no se resuelven automáticamente.
- Revisión mensual del conocimiento.
- Secretos, datos sensibles y estado transaccional nunca entran en Obsidian.

## Alternativas descartadas
- Resolver contradicciones por "mayor confianza" (rechazado: la confianza es subjetiva y puede consolidar errores).

## Consecuencias
- Memoria fiable y auditable.
- Contradicciones visibles y revisables.
