# Catálogo activo de Skills para Trading MVP

## Propósito del catálogo activo

Este catálogo reduce ruido contextual para agentes durante la construcción del **Trading MVP**. Se priorizan skills técnicas y de control alineadas con la arquitectura canónica y la regla de **Preservation of Capital**.

## Reglas de activación

- **Solo** las skills bajo `.claude/skills/` se consideran activas para el Trading MVP.
- `.claude/skill-library-archive/` es una biblioteca **pasiva** (referencial), no activa por defecto.
- Cualquier skill/integración externa archivada solo puede volver al catálogo activo tras **ADR aprobada**.

## Novedades — Trading MVP skills (2026-08-26)

Se añadieron **11 skills nuevas** para el Trading MVP, todas con `SKILL.md` estructurado y reforzando la regla de **Preservation of Capital** (cálculos cuantitativos deterministas; LLM solo para interpretación):

- **`00-core`**: `context7-docs`, `playwright-e2e-testing`, `python-security-hardening`, `superpowers-methodology`.
- **`02-trading`**: `market-data-ingestion`, `order-execution-patterns`, `portfolio-risk-management`, `exchange-connectivity`, `signal-generation-patterns`.
- **`04-operations`**: `exchange-api-monitoring`, `trading-system-deployment`.
